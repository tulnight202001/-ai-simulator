技術與架構

  • 平台：Vite + TypeScript + Phaser 3，手機優先的 PWA，靜態部署。
  • 邊界：data/ 保存模型、工作區、配方、客戶與關卡；core/ 保存純規則；game/ 負責 Phaser 場景、輸入與呈現；services/ 負責 IndexedDB、備份及平台能力。
  • 可重現性：每個生涯保存 seed 與亂數狀態；關卡與任務生成只透過種子亂數。
  • 存檔：版本化 IndexedDB，多模型存檔；所有持久資料經 migration 邊界存取。後續加入 JSON 預覽／匯入及選配 Google Drive adapter。
  • 即時遊戲：固定斜上方場景；鍵盤移動與點擊設備共用角色導航／互動狀態機；設備與資料箱都是場景物件而非表單。
  • 離線：service worker 快取 app shell 與資產；核心內容不呼叫 AI 或付費 API。
