可測試方式

理想環境執行 npm install && npm run dev，瀏覽 Vite URL；選模型後到櫃台領箱，依 HUD 先後前往設備，最後回櫃台。可把時間暫改或完整等待 180 秒查看結算與 IndexedDB ai-simulator。
